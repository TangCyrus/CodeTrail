# CodeTrail 0.3.0 命名迁移验证

日期：2026-11-06。环境：Windows 11、Node.js 24.20.0、npm 11.19.0、Git 2.55.0.windows.5、Codex CLI 0.166.0-alpha.6。

## 变更范围

产品名统一为 CodeTrail；npm 根包为 codetrail，五个工作区包为 @codetrail/local、@codetrail/web、@codetrail/analyzer、@codetrail/graph、@codetrail/shared。内部依赖、源码类型导入及锁文件同步更新，项目和 MCP 版本升为 0.3.0。分析器版本也更新，避免沿用不同忽略配置约定下的快照身份。

CLI 与 Windows 启动器改为 codetrail / codetrail.cmd；MCP 服务及 Codex 配置改为 codetrail，指引资源为 codetrail://guide。Skill 文件夹、frontmatter、示例调用与元数据中的 MCP 依赖全部对应 codetrail-understand / codetrail-impact。

项目忽略文件与测试样例改为 .codetrailignore，内置忽略目录改为 .codetrail，默认缓存基目录为 CodeTrail，浏览器会话键为 codetrail.session。专用环境变量前缀改为 CODETRAIL_，标准 OPENAI_API_KEY 保持可用。AI 结构化输出的 schema 名称改为 codetrail_explanation。

前端标题、品牌、服务端提示、演示标识、安装包名称、测试脚本与当前文档均同步更新。旧入口不提供别名；升级步骤见 [命名迁移说明](命名迁移说明.md)。历史阶段产物身份与哈希仍保留原始记录。

## 验证结果

- `npm ci --ignore-scripts --offline` 成功：新工作区链接和 node_modules/.bin/codetrail 三种启动文件存在，旧包命名空间及旧命令入口已移除。
- `npx --offline codetrail --help` 成功，实际命令入口输出 CodeTrail 标题和三种子命令。
- `npm run check` 通过：**82 项 Node 测试，零失败**；原解析金标准在标注范围内 FP/FN 均为零。日志：artifacts/naming-migration/check.log。
- `npm run test:browser` 通过：**20 项浏览器测试，零失败**。额外核实 CodeTrail 页面标题、品牌、新会话键及刷新后的继续访问。日志：artifacts/naming-migration/browser.log。
- 环境变量读取验证专用密钥优先级、模型、服务端地址与推理设置；模拟 Responses 请求确认新 schema 名称。测试不调用真实模型。
- 解析测试确认新忽略文件生效，并跳过 .codetrail 目录；Git 双快照相关测试使用新的忽略文件名。
- 两个 Skill 均通过 skill-creator 的 quick_validate.py 校验，宿主实际读取其名称与 MCP 依赖。
- `npm run validate:codex` 通过：实际宿主连接 codetrail 0.3.0，发现两个新 Skill、六个工具和 codetrail://guide，完成九次工具调用。仍为确定性协议验收，模型生成次数为零，不代表模型自主工具选择或业务解释质量已验证。记录：artifacts/agent-acceptance/codex-acceptance.json。

本次也修复了已有测试的隔离缺陷：工程初始化为真实 Git 仓库后，放在其子目录的“无仓库”样例会向上发现工程仓库。现在仅将这两组样例放到系统临时目录，清理前仍校验绝对路径范围，保留真实的无 Git / 无 HEAD 断言；没有改变生产 Git 查找逻辑。
