# CodeTrail 试用反馈记录（空白模板）

复制后填写，一份对应一位参与者、一个项目、一个条件。模板不是已收集数据；未测字段保持空白或写“未测”，不要填 0、成功或默认满意。工程预跑不得填写真人身份、耗时改善或满意度。

## 会话信息（主持人）

- 记录类型：真人试用 / 探索性试用（选择一种）：
- 匿名编号、经验组（新手/熟练）、TS/JS/Git/Agent 经验：
- 日期、主持人、评分核对者（没有则“未复核”）：
- 任务版本（trial-v1）、项目 A/B、源码 HEAD、是否接触过该项目：
- 条件 T/C、执行顺序、第几个条件、实际分配偏离：
- CodeTrail 版本、Codex 版本、模型和参数；C 条件是否已禁用 MCP/Skill：
- OS、Node/Git、声明依赖准备方式、MCP 项目根目录：
- 安装/接入实际秒数、首次分析等待、是否需要帮助或发生网络故障：
- 观察记录/源码片段保存是否获同意（不保存会话凭证、密钥和真实姓名）：

## T1：理解陌生项目

- 参与者原始答案（三个职责、入口、调用关系、3–5 步阅读顺序）：
- 状态（independent / assisted / timeout / blocked / abandoned）：
- 实际秒数、时限 600 秒、暂停秒数及原因（等待计入实际时间）：
- 信心 1–5（交卷前由参与者填写）：
- 源码证据（snapshotId 或 HEAD、文件、行号、哈希；实际打开次数）：
- 规则候选、推断、不确定边界：
- 主持人帮助的时间、原话、类型（操作/位置/答案/代操作）：
- 评分四点（模块依据/入口区分/源码调用必需/阅读与边界，各 0 或 1）、合计 /4、正确性是否通过：
- 卡点、影响、绕行方式、问题编号：

## T2：定位修改点

- 参与者原始答案（目标符号/语句、修改边界、调用者、测试检查）：
- 状态（independent / assisted / timeout / blocked / abandoned）：
- 实际秒数、时限 480 秒、暂停秒数及原因：
- 信心 1–5：
- 源码证据（snapshotId 或 HEAD、文件、行号、哈希；实际打开次数）：
- 测试线索来自图谱还是普通搜索；没有路径时的处理：
- 主持人帮助的时间、原话、类型：
- 评分四点（精确定位必需/修改边界/调用依据/测试与行为，各 0 或 1）、合计 /4、正确性是否通过：
- 卡点、影响、绕行方式、问题编号：

## T3：改动影响分析

- 主持人应用的单处练习差异、原文恢复记录（未经执行的演练）：
- 参与者原始答案（旧新语句、调用者、相关测试建议与依据）：
- 状态（independent / assisted / timeout / blocked / abandoned）：
- 实际秒数、时限 720 秒、暂停秒数及原因：
- 信心 1–5：
- comparisonId、HEAD、两侧 snapshotId；C 条件旧新原文来源：
- 每条关键路径的 side、起点/目标、每步关系、evidenceId、文件/行号/哈希：
- 两侧 status/诊断、external/gaps、baselineDependencies 状态与拒绝原因：
- 概览截断原因、是否改为符号聚焦、聚焦仍有的截断、是否完成分页：
- 恢复后旧报告是否过期、两侧练习源码是否保留、新比较 ID 与零改动结果；C 条件 diff 结果：
- 主持人帮助的时间、原话、类型：
- 评分四点（变化正确/同侧调用证据必需/测试与边界/恢复核验，各 0 或 1）、合计 /4、正确性是否通过：
- 是否混用版本、用过期证据解释当前代码，或把路径说成执行/覆盖证明：
- 卡点、影响、绕行方式、问题编号：
