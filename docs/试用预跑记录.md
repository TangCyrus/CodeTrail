# 小范围试用工程预跑记录

日期：2026-11-09。任务版本 trial-v1，运行版本 CodeTrail 0.10.0；源码参考提交 `4407f7510c21d1b3d1d46df5940b6219290966f2`。本轮是由脚本选定工具与断言的工程预跑，没有招募参与者、没有模型生成，没有用户评分、满意度或效率改善数据。

## 场景与取证方式

两项目均通过新建 stdio MCP 进程运行六类工具中的实际查询，固定 snapshotId/comparisonId，使用本机原有声明准备环境，不联网补装目标依赖。工程脚本 `scripts/validate-user-trial.mjs` 不构建或执行练习差异；它验证查找、关系及证据流程，不能证明临时改动的运行时行为或模型自主调用效果。

- T1：概览 → 阅读推荐 → 指定架构节点搜索与源码 → 静态调用证据。记录推荐顺序，人工解释和职责推断不由脚本自动评分。
- T2：精确搜索 `compareSnapshots` / `shallow`，核对目标语句、上下游及源码。普通文件工具核对相关测试原文与哈希，并区分 `shallow` 与另一个函数 `compareShallow`。
- T3：临时施加一处指定差异 → 原快照过期且源码保留 → HEAD 比较 → 两侧符号搜索、独立聚焦及分页 → 调用依据与旧新语句 → 恢复原字节 → 旧比较过期且两侧练习源码仍保留 → 新比较零变化。保存的全部文件哈希与证据切片亦逐条校验。

## 本轮处理与保留的问题

- UT-01，试用准备已修正：旧材料缺少可以照做的修改定位任务、受控差异、必需证据检查与恢复步骤。已拆为三个任务卡、0–4 分标准及完整反馈模板，帮助、超时、阻断与独立完成分开记录。
- UT-02，评分依据已修正：仅凭 React 的 `describe('shallow')` 标题容易误认直接测试调用。源码核对发现它调用的是 `compareShallow`，而 `shallow` 的直接测试依据在 Preact。主持人答案已纠正，复验加入单独定位 `compareShallow` 及防止错误直接调用路径的检查。
- UT-03，P2 保留：CodeTrail 自身的 `.mjs` 测试不在当前扫描范围。反馈/任务标准要求用普通搜索补查，并将来源标记为普通文件核对；不把图中缺失称为没有测试。
- UT-04，P2 保留：本项目默认阅读推荐偏向工作台 App，还包含 examples 的入口，不会自动围绕“MCP 链路”重新排序。指定任务的搜索与源码入口可完成理解，推荐的任务相关性留待真人观察，不将脚本能打开推荐视作推荐质量通过。
- UT-05，已知环境边界：TanStack 仍有声明/动态关系缺口和 HEAD 锁身份拒绝；保持真实状态，不在预跑中补造类型、扩大源码范围或假定所有框架调用均已解析。具体政策见 [HEAD 依赖验证](HEAD依赖环境验证记录.md)。

本轮没有发现需要修改解析器或 MCP 生产代码的核心阻断。升级后仍须重载常驻 MCP，正式任务前核对版本、项目和 `stale: false`；仅刷新分析不等于重载服务。未解决的 P0/P1 将阻止邀请，现有 P2 须带已知绕行方式进入试用。

## 复现与记录

在完整源码仓库安装并构建后，准备既有专用外部克隆及声明环境，参考 [外部项目验收](外部monorepo验收记录.md) 和 [依赖准备](依赖与未构建入口验证记录.md)。预编译 ZIP 仅提供试用文档，不含下面的开发验收脚本或外部源码。

```powershell
npm ci --ignore-scripts
npm run check
npm run validate:trial
# 也可逐个项目运行
npm run validate:trial -- --project self
npm run validate:trial -- --project tanstack
```

脚本要求演练目标与 HEAD 一致，外部克隆必须为固定提交且干净。仅改动目标文件的一处语句，finally 在内容仍与原文/演练版本一致时恢复，不覆盖并发编辑；目标源码发生并发变化时报告失败并保留编辑。不要同时构建 CodeTrail 源码或运行另一个会修改相同目标的验收脚本。

各次记录位于 `artifacts/user-trial/prerun-*/result.json`，单项目另有实际 `tool-calls.json`、两侧快照与保留源码的本地缓存。`artifacts/user-trial/latest.json` 只是最近一次完整调用的索引，单项目运行会覆盖索引；历史目录仍保留。产物含源码，不提交仓库、不当作真人反馈。试用组织与扩大门槛见 [方案](用户试用方案.md) 和 [标准](试用验收标准.md)。
